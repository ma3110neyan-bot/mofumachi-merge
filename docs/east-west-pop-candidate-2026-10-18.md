Unity Hubは起動したままで構いません。Unity Editorを閉じ、次の1行をPowerShellへ貼り付けます。

```powershell
& { $ErrorActionPreference="Stop"; Set-Location -LiteralPath "C:\Users\User\Desktop\Mofumachi\mofumachi-merge"; if(-not (Select-String -LiteralPath ".\Assets\Mofumachi\Presentation\TownNextGoal.cs" -SimpleMatch "public static string CompactDetail" -Quiet)){throw "先にGitHub DesktopでPullしてください。"}; powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File ".\scripts\build-android.ps1" -TownQa }
```

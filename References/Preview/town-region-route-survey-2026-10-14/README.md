# B案の地域内の道と足元

元絵を変更せず、地域内の線と独立した除外候補を重ねた設計／初期確認図。青線は現在のカタログ、赤はテスト側で読取り調査した家具・花壇・庭。ピクセルの描き替えではない。

![足元と除外候補](side-paths-and-obstacles.png)

7件のCore経路検査は成功。独立した矩形は絵全体の完全な障害物マスクではない。正式キャラの足元幅・札・HUD・通路の見た目はUnityとPixelで未検証。

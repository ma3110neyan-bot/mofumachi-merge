## 街QAだけを保存維持で更新

今回の記録更新だけでPull・再ビルドを繰り返す必要はない。PixelをUSB接続し、ロックを解除してUSBデバッグを許可する。次のブロックはローカルAPKを原本のSHAに照合し、端末と既存街QAのIDを明示して既存installerのinstall-rで更新する。アンインストール／保存消去は行わない。

```powershell
& {
    $ErrorActionPreference = "Stop"
    Set-Location -LiteralPath "C:\Users\User\Desktop\Mofumachi\mofumachi-merge"
    $MofuApk = ".\Builds\Android\20261026-093151-b7d557b1\town-life-qa.apk"
    $MofuHash = "2971b220edc77a7605ded12295bf2b7cbf06b83cbdcca9a86d03175694498cf0"
    if ((Get-FileHash -LiteralPath $MofuApk -Algorithm SHA256).Hash -ne $MofuHash) { throw "APKのSHA256が一致しません。更新を停止しました。" }
    powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File ".\scripts\install-pixel3a.ps1" -Apk $MofuApk -PackageName "com.mofumachi.merge.qa.townlife" -Serial "99RAY1BELH"
    if ($LASTEXITCODE -ne 0) { throw "更新が停止しました。この出力を確認してください。" }
}
```

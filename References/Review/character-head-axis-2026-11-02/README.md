個別JPEGには正面・左・右・背面、静止・歩行2位相、首元拡大を収録しています。Beforeは今回指摘されたfffcfe5、Afterは今回の修正候補です。

## 今回の変更

変更は **頭の左右位置7箇所だけ** です。

|キャラ|修正した向き|変更|
|---|---|---|
|ノア|左|頭を右へ寄せる|
|モモ|左／右|それぞれ胴体側へ寄せる|
|ルル|左|頭を右へ寄せる|
|ポム|左／右|それぞれ胴体側へ寄せる|
|フィオ|なし|ユーザー合格の配置を維持|
|ミエル|左|頭を右へ寄せる|

上下の襟接続だけを検査していた前版では、左右に共通の−20／＋20が残っていました。今回は頭・胴体の中心軸を個別に確認し、7方向のX登録だけを補正しました。Y登録18箇所、指摘のない11方向、フィオ全方向、頭以外の頂点と頭のサイズ・角度は前版と同じです。正式原画・衣装・顔・色・体型・表情・歩行速度・影・向き方式等も変えていません。

`horizontal-scope-verification.json` は変更範囲の検査、`collar-verification.json` は原素材の襟被覆／衣装非被覆の検査です。各1774モデルframeの実Graphic頂点検査と、各1308分割frameの原素材検査を実施しています。計算の成功だけで見た目の合格とは判定しません。

## 見本の性質

すべて **正式素材と実描画コードからのソフトウェア再現JPEG** です。Unity／Pixelの実画面ではありません。生成AIや画像側の頭の切り貼りで位置を直したものではありません。ゲーム内のHead登録値を変更し、その実Graphic出力を描画しました。原画やユーザー添付の見本一覧は編集していません。

フィオの前版配置は全方向そのままです。残り5名の今回の見た目は修正候補で、正式な再合格とは宣言していません。実Unityの連続確認・正式固定・全件テスト・Pixel・Merge工程には進んでいません。

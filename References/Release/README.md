# ストア素材候補

2026-10-09、image_genで街・家・噴水・花だけを新規生成。正式6名の原画に変更はありません。ゲーム内背景の差し替えや正式採用はしていません。

- `icon-proposal.png`：正方形の生成マスター候補。
- `feature-graphic-proposal.png`：横長の生成マスター候補。

生成ツールは指定した512×512／1024×500をそのまま出力しなかったため、これらを提出寸法済みと呼びません。Windowsで `powershell -ExecutionPolicy Bypass -File .\scripts\export-play-art.ps1` を実行すると、原本を残したまま `icon-512.png` と `feature-graphic-1024x500.png` を書き出します。このWindows画像書き出しはクラウド未実行です。最終素材確認、アプリ用adaptive icon設定、実機スクリーンショットは公開前に必要です。

候補画像は実機スクリーンショットではありません。ゲームの機能や到達できる街の状態を誤認させないストア表現へ仕上げてください。

# ノア1名：立体感集中パス

ユーザーは動きを合格方向、2.5Dの見た目を不合格とし、影とパーツの奥行きに集中するよう明示した。既存の歩行／表情／1秒の挨拶の時間設計を土台にする。正式原画の顔・目・衣装・配色・体型・シルエット、他5名、街・北境界・噴水・図鑑・BGM・Merge・Save等は維持する。フル3Dや原画の描き直しはしない。

比較原本はsource22f2831／run123240。現状は接地影が名札上端／足の下で読みにくく、全身のyawとleanが主で、顔と胴の相対的な向きの差が弱い。

選択した内部方式：同じatlasと既存UGUIメッシュで、顔・胴・左右の腕／脚へ小さな前後差を与える。顔と目の領域は一つの剛体として動かし、顔の内部をせん断しない。胴より顔を先に向け、歩行の位相と前後移動方向から小さな前後揺れを作る。接地足はyaw／pitch／rollと呼吸後の実頂点から床Yを解き、影は歩行座標へ追従して上下に跳ねない。影は1Graphic／97頂点を維持し、足の横と名札より上へ柔らかく広がる楕円とする。UV・alpha・元atlasは維持し、明暗はRGB同率の控えめな範囲に制限する。

検討した代案：影と色だけの増強は前回の弱い差に留まりやすい。独立スプライトを描き直す方式／フル3D／重い照明は原画・負荷の制約に合わない。上の軽いパーツ差方式は担当側の実装判断であり、ユーザーの見た目の採用承認を意味しない。

現行22f2831の計算・影・メッシュをBeforeとして保持する新しい表示切替を使う。旧1d11629／2Dの歴史的切替も残す。原画の顔／尾や旧比較を別の見た目へ差し替えない。表示だけの切替をSaveや製品UIへ追加しない。

既存のノア単体撮影メソッドをprotocol2へ更新。静止／左歩行／停止／左右転換／会話／挨拶に、実際の前後歩行と影だけの比較を加える。連続標本は1/30秒2stepごと、222コマ／14.8秒とし、前後も実公開GuidePointで動かす。固定標本を実時間FPSと呼ばない。別記の影比較では身体を同じAfterのまま保つ。すべて同じ瞬間／カメラ／モデル／水／Saveを保持し、差分範囲を広げて合格させない。

途中はノアのCPU幾何・モーション、関連Unity API compile、撮影validatorの最小fixtureのみ。実画像の明確な改善で承認候補となるまで全件QAは保留。クラウドでは新しいUnity実描画／Pixel USBは使えない既知の制約を再試行せず、未確認を明示する。Pixelは後の候補確認でSave維持の更新と負荷計測を行い、Fresh／uninstallはしない。採用・他5名への展開にはユーザー承認が必要。

この詳細指示とAGENTS13により、承認済み方向の内部選択を再確認で止めず実装する。原画の設計変更／大規模方向変更が必要になった場合は別途確認する。

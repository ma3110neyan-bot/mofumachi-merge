# ノア比較撮影：名札の条件を揃える修正

受領した `noah-pair-20261028-205828-8cdc5361.zip` はsource5860f9c、単体テスト1件失敗。原本10ファイルは `References/Review/noah-pair-2026-10-28-205828/native/`。実PNG／JPEG6枚を全デコードし、JSONのPNG SHA／bytes、原XML／source-infoを照合した。

## 確認した原因

会話比較 `37-noah-talk` の全差分19665画素、ノア範囲外5621画素を再計算。範囲外はモモの名札が非表示→表示になった部分と影で、左上原点bboxはx513–660／y751–795。Graphic状態もモモ名札とそのTextの表示切替だけを示した。他5名の体・座標・カメラ・噴水位相・保存状態の不変検査は成功。

既存の名札はキャラの矩形との重なりを避ける。名札上端y528.7273に対し、旧描画のノア矩形下端y528.5933は約0.134px重なり、新描画の下端y529.6482は離れる。これが名札表示を変え、キャラ本体だけの比較範囲外として検出された。ゲーム本体を直して検査へ合わせる必要はない。

## 変更

製品コード・原画・街・北境界・噴水・BGM・保存・他5名は変更しない。修正対象はテストの比較条件と提出用の出力のみ。

1. 製品Afterを通常どおり描画し、6名の名札表示状態を取得。
2. 旧描画の自然なBeforeも撮る。
3. 比較用Beforeだけ、名札表示を製品Afterの状態へ揃えて再描画。
4. Afterは介入なしの自然な製品表示で撮る。名札の状態・画面の他要素が安定しているか検査。

制御できるのは実際の住人名札Graphicの表示フラグのみ。他のGraphicの位置・色・型や、Actor／モデル／カメラ／水の時計／保存を変えない。ノアの比較矩形も「範囲外0」も従来どおり。名札を全面非表示にしたり、差分をマスクしたり、Before/After画像を加工したりしない。

自然なBeforeで名札が異なる場合は、`37-noah-*-ui-natural-before.png` と6名分の表示状態を必ず保存する。通常Afterと並べて本来の表示切替も確認できる。自然Beforeは検査で失敗しても破棄せず、失敗JSONへ識別情報を残す。

提出メタデータはversion3。Afterが自然表示であること、制御がBeforeの名札表示だけであること、6名の状態と自然Before PNGのSHAを検査する。v1/v2は過去原本の検証だけに残し、現在の受入には使わない。Beforeは条件を揃えた再現であり、旧APKのそのままの映像／同じ経過時間の挨拶ではない。

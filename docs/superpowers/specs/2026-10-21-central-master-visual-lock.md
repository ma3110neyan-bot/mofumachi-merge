# 中央広場マスターと正式Visual Lock

ユーザーの2026-10-21「ベース版復旧・Visual Lock・後退防止」指示を仕様とする。提示済み `References/Preview/design-first-2026-10-21/design-proposal.png` は正式承認された品質基準。生成画像そのものを実Unity／実装済みと呼ぶことは引き続き禁止。

## 今回の工程

1. 承認画像・SHA・復旧点を固定。
2. 中央広場だけを制作。非反復の描き込んだ地表、噴水、花、木、建物、街灯、ベンチ、小物を、既存の連続座標・奥行き順に重ねる。既存の道幅・四方向の出口・噴水両側・滞在点を保つ。中央以外の配置とMergeはこの工程で改修しない。
3. 同条件のLv1／3／6で前版・正式Visual Lock・実Unity候補を比較。見た目と歩行の合格がないうちは中央を採用しない。
4. 中央合格後にのみ、西→東→北→南→接続→Merge→UI→基本ループ→Unity全件→QA APK→Pixel受入へ進む。

## 中央の実装

- 一枚の全5地区背景へ戻さない。中央の地表画を固定ワールド座標へ配置し、実際の建物・家具・植栽・噴水・キャラを奥行き順に描く。中央マスターの地表はUI／キャラ／独立物の焼き込みを含めない。
- 地表画は中央の既存歩行面・植栽の足元をガイドに制作。小さな草花・地表の彩りでLv1から景観を整え、既存の硬い物体の基礎と歩行判定を対応させる。歩行のための大きな芝生の空白や、反復テクスチャによる設計図感を避ける。
- 独立物は既存の正式素材を利用。新しい中央装飾は最初から見える基礎を持つか、既に歩けない植栽区画を飾る。成長装飾は完成した初期景観への追加・置換。
- 描画は同じ `TownContinuousWorldView.Local` の投影を使用。通常の移動に白画面・フェード・背景切替を入れない。新しい画像は非Readable・圧縮・上限2048で導入し、負荷合格はPixel実測まで保留。
- 元の画像／音源／Core／図鑑／日次／TOPは変更しない。SaveData・安定ID・5×6・依頼・納品・報酬・正式6名は維持。

## 比較・採用

前版は実行20261021-113845-fbcafb0d（製品bd3f357）の実Unity画像。dfc2a92は未採用候補であり「良かった版」と見なさない。作業前7085af7は復旧用タグに退避し、ハードリセットやセーブ初期化をしない。

従来の見た目／操作／情報／世界観／FPS／Pixel負荷に、街密度／Mergeの楽しさを明示して判定する。未確認は合格にしない。明確に悪化した場合は該当候補を採用せず、記録した前版へ戻して再設計する。

中央専用のネイティブレビューはPNGと比較JPEGを生成し、APKは生成しない。正式Visual Lockの原本とBeforeは書き換えない。中央が未合格の間は全体QA APKへ進めない。

## 環境と完了条件

現在のクラウドはUnityライセンス不足・Android Build Supportなし・Pixel USB経路なし。実装、DLLコンパイル、素材プレビューをUnity／Pixel合格へ置き換えない。中央の実Unity確認が阻害される場合は、その手前まで制作と検査を終え、他地区やMergeを先行せず中央レビュー待ちとして止める。

最終合格はUnity実画面で基準相当＋Pixel正常操作＋前版より明確に良いこと。新規CITY／ガチャ／時間帯／季節／キャラ／Merge系統／大規模ショップ／本格2.5Dは行わない。

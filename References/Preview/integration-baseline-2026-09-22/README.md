**2026-10-18の最新方針を優先します。** 原本のやさしい世界観・POPな操作導線・読みやすさを基準に、街は「西のカフェ通り／中央広場／東の花屋通り」、Mergeは見やすい平面寄りの5×6盤面へ調整します。過去の斜め盤面・厚い受け皿を維持する記述は今回の表示方針を上書きしません。[一括候補と実機確認の状況](../../../docs/east-west-pop-candidate-2026-10-18.md)を参照してください。

以下は方針変更の履歴です。

2026-10-13、ユーザーが6画面コラージュを再添付し、今後の街・Merge・UI改善で「9月22日の基準イメージ」として扱うよう指定しました。

- Merge：まとまったアイボリーの盤面、温かな縁、アイテムの種類と選択情報、明確な操作導線。

最新の統合本線は、このチャットへ共有される引き継ぎ本文です。今回「9月22日の基準画像を最上位のビジュアル基準とし、正式6名と最新の街／Merge／フォント方針を統合する」という指示を受領し、[現状分析・対象ファイル・改善案](../../../docs/superpowers/specs/2026-10-13-integration-baseline-review.md)へ反映しました。方針確認後に段階実装します。未共有のページ本文へアクセスしたとは扱いません。

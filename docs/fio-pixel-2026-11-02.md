# フィオ左右の微調整後：6キャラをPixel 3aへ直接更新

今回の修正は **フィオの左右2方向のHead Xだけ**。左は−20→−12、右は20→12と胴体側へ微調整しました。ほかの5名、フィオ背面、上下位置、サイズ、角度、原画、歩行・向き・会話等は維持しています。

最新ユーザー指示により、画像承認・Unityテスト・全件テストを挟まず、既存の直接APKルートを使用します。Unity Hubの操作は不要ですが、APK作成のためUnity本体が自動起動します。

Unity Editorを閉じ、Pixel 3aをUSB接続して画面ロックを解除した状態で、Windows PowerShellへ以下全体を貼り付けてください。

```powershell
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -Command {
    $ErrorActionPreference = "Stop"
    Set-Location -LiteralPath "C:\Users\User\Desktop\Mofumachi\mofumachi-merge"
    . ".\scripts\build-android.ps1"
    $mofuPixelGit = Find-SourceGit
    $mofuPixelBranch = & $mofuPixelGit branch --show-current
    if ($LASTEXITCODE -ne 0 -or $mofuPixelBranch.Trim() -ne "feat/daily-world-pass-20261016") {
        throw "作業ブランチが異なるため停止しました。"
    }
    & $mofuPixelGit pull --ff-only origin feat/daily-world-pass-20261016
    if ($LASTEXITCODE -ne 0) { throw "更新に失敗したため停止しました。" }
    & ".\scripts\prepare-characters-direct-pixel.ps1" -Install -Serial "99RAY1BELH"
}
```

新しく作った6名入りAPKだけを、Pixelの「もふまちメルジュ 街QA」へ上書き更新して起動します。USBデバッグの許可が端末に出た場合は許可してください。アンインストール、保存データ削除、街やUIの変更、追加の模擬機能はありません。

Pixelでは6名の左右・前後移動、歩行中の方向転換、停止・再歩行をそのまま試せます。画像の再承認待ちはありません。

新規出力は `Builds/Diagnostics/characters-direct-pixel-日時-ID/`。現在のソース・資源・APKのハッシュが一致した場合だけインストールします。失敗時は今回のログを保持し、過去のAPKで代用しません。

クラウドではフィオ関連の1774モデル姿勢、原素材の襟検査、非対象不変、APIコンパイルと直接ビルド経路の関連ガードのみ確認しました。実Unity描画・APK作成・実機テストの成功はWindows／Pixelでの実行後に判定します。正式固定・全件QA成功とは先に宣言しません。

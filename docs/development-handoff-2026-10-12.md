## 2. 今回実装・修正した内容

- UI／質感：Mergeアイテムの原画像とUV・シルエットを維持し、同じ共有画像を使う薄い落ち影を1枚のメッシュに追加。セルの金縁・光沢を微調整し、既存Lv.欄の背面に茶器／パン／花の淡い色のバッジ。Lv.文字のサイズ・領域は維持。
- 操作：選択したアイテムの絵だけを約0.12秒で1.06倍へ。セル・タップ範囲・Lv.文字は拡大しない。選択時に既存案内欄へ種類とLv.を表示。通常の再描画では選択の動きを繰り返さない。
- 合成：保存が成功した結果だけ、約0.08秒の寄せ→完成アイテムの小さな弾み。操作ロックは既存の0.22秒を維持。光は最大0.5秒、星8粒と淡い光1つ。常時の全マスアニメーションは追加しない。
- 安定性：1つの演出層と3つのアイテム表示を使い回す。演出は入力を遮らず、失敗・拒否では開始しない。後段の保存エラーは残りの光を停止。通常の再描画・退出・pause・レイアウト変更で片づけ、合成完了時の意図した再描画だけ光の余韻を保つ。
- ドラッグ：既存ドラッグ画像にも陰影を適用。サイズ変更で古いドラッグ表示を除去し、その指の終了イベントでアイテムを移動・消費しない。
- ゲームロジック／保存：Core、保存v3、アイテムID／Lv.1〜3、依頼、消費、報酬、街成長ルールの変更なし。演出の経過・選択アニメーションは保存しない。
- キャラ／街／音：正式画像、街背景、ロゴ、音源、街の行動範囲は変更なし。

## 10. Windows PCで次に行う作業

1. Unityを閉じる。
2. GitHub Desktopのmofumachi-merge／mainで**Fetch origin→Pull origin**。
3. Unity HubからUnity6000.6.4f1で開き、インポート／コンパイル完了を待つ。
4. Window→General→Test Runner。EditModeのRun All、PlayModeのRun All。PlayModeは**60件全成功・失敗0・skip0**が今回のソース上の目安。両方のExport ResultsでXMLを保存。エラーが残る場合は詳細を確認してからビルドする。
5. 合格後、Mofumachi→Android→**Build Town QA APK (separate save)**。`MOFUMACHI_APK_SUCCESS`を確認。
6. PixelをUSB接続し、ロックを解除したままPowerShellで実行：

```powershell
$MofumachiRepo = "C:\Users\User\Desktop\Mofumachi\mofumachi-merge"
powershell -NoProfile -ExecutionPolicy Bypass -File "$MofumachiRepo\scripts\install-pixel3a.ps1" -Apk "$MofumachiRepo\Builds\Android\town-life-qa.apk" -Serial "99RAY1BELH" -PackageName "com.mofumachi.merge.qa.townlife"
```

`Installed ...`とAPK SHA256を保存。更新は既存の街QAセーブを保持します。今回版を起動してチェックリストを確認してください。

Unityを閉じてXML検査・ビルド・SHA記録をまとめる場合は、手順4・5の代わりに：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$MofumachiRepo\scripts\build-android.ps1" -TownQa
```

この方法は日時付きフォルダへ出力します。インストールの`-Apk`を実際に出力されたパスへ差し替えてください。

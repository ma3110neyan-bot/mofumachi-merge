南の庭園候補：Unity実画面の確認手順（APKは作りません）

1. GitHub Desktopで feat/daily-world-pass-20261016 を選び、Fetch origin → Pull origin。
2. このプロジェクトを開いているUnity Editorを閉じる。
3. Windows PowerShellへ次のまとまりを貼り付ける。

& {
    $ErrorActionPreference = "Stop"
    Set-Location -LiteralPath "C:\Users\User\Desktop\Mofumachi\mofumachi-merge"
    if (-not (Test-Path -LiteralPath ".\Assets\Mofumachi\Tests\PlayMode\SouthMasterReviewTests.cs")) {
        throw "南の修正版が未反映です。GitHub DesktopでPullしてください。"
    }
    powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File ".\scripts\build-android.ps1" -SouthReview
    if ($LASTEXITCODE -ne 0) { throw "確認が停止しました。表示された出力先のcentral-playmode.logとcentral-playmode.xmlをお送りください。" }
}

この呼び出しは実行ポリシーを子PowerShellのみに指定します。親の設定変更や管理者起動、スクリプトのドット読み込みは不要です。

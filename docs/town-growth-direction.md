# 依頼の成果が景色に残る街づくり

2026-10-11（日本時間）。**仲間の依頼を受け、マージで品物を作って届け、その成果で街を育てる**コンセプトです。ユーザーが選択した「章ごとの依頼・街成長で、最初から一区切りまで遊べる構成」に合わせ、[3章6依頼の具体案](superpowers/specs/2026-10-11-chapter-game-design.md)を作成しました。章・Lv.4〜6の外観は設計確認待ちで、未実装です。

## 現在の実装

正式6名から主人公を選び、街の道に沿って指で移動できます。他5名の往来・短文会話、依頼部屋への到着後の入室、ショップの準備中案内を接続済み。全身は採用された見本と通常・笑顔・驚きの3表情で、独立した脚の歩行コマはありません。移動がぎこちないとの最新FBを受け、更新と反応の修正を設計しています。

お茶／パン／花の各Lv.1〜3、6件の依頼が現カタログです。新規データから各1回完了すると330 Coins／街Lv.6。同じ依頼の再納品で報酬や街Lv.を増やすことはできません。旧1件完了の30 Coins／Lv.1データも続行する設計です。

現在の外観は共通背景に小さな装飾を重ねます。Lv.1で花、Lv.2で追加の花飾り、Lv.3で噴水周りの星の光、Lv.4以降はLv.3外観を維持します。建物を配置する自由建築、ショップ購入、別の街背景は未実装です。今回のPDFではTOP・案内・主人公選択を確認できましたが、街移動・成長・保存復帰の実機合格は未確認です。

## 最初の物語に向けた成長案

街の道・建物の位置と明るいグラフィックを維持し、固定装飾を積み重ねます。既存Lv.1〜3を取り除いたり、保存の街Lv.を変えたりしません。

| 街Lv. | 景色に残す変化 | 状態 |
| --- | --- | --- |
| 0 | 現在の街と噴水 | 共通背景を維持 |
| 1 | 小さな花 | 仮実装 |
| 2／章1終了 | 広場の花飾り | 仮実装。章末の案内は提案 |
| 3 | 噴水周りの星の光 | 仮実装 |
| 4／章2終了 | 広場の縁と店先の歓迎リボン | 提案・未実装 |
| 5 | 入口脇の花のアーチ | 提案・未実装 |
| 6／章3終了 | ガーランドと広場のお祝いの彩り | 提案・未実装 |

章1はルルとモモの依頼、章2はミエルとポム、章3はフィオとノア。6名全員へのお届けを通じて、最後に育てた街で「最初の物語完了」を迎える案です。章ボーナスや新しい通貨は増やさず、現在の6依頼・品物・報酬を使います。

成長した場所だけ1秒程度強調し、少量の花びら・きらめき・仲間の笑顔を添えます。噴水の水流は街全体表示で分かる濃さと速度へ調整。装飾や吹き出しで道・入口・操作ボタンを隠さず、Pixel 3aの負荷を測定します。

装飾は背景のUV位置と保存済み街Lv.から表示します。成長演出を途中で閉じても、再開後に完成した景色が戻り、報酬は増えません。Lv.6以上はLv.6外観を保ち、数値を下げません。

## 固定する素材と公開の条件

正式名はモモ・ルル・ポム・フィオ・ミエル・ノア。元の顔・配色・衣装・シルエットと採用された全身見本を維持します。[正式参照](../References/Characters/mofumachi_6characters_master.png)の旧名へ戻しません。主人公は指で動かし、依頼部屋・ショップ前で指を離して入室する導線を保ちます。

3章の設計・演出・見本の作成だけで公開可能とは判断しません。全6件を遊び切ること、旧セーブからの続行、Pixelの移動・全画面・音・再起動復帰・安定性、正式音源と提出準備が必要です。[現在の実装・残件・確認手順](development-handoff-2026-10-11.md)を参照してください。

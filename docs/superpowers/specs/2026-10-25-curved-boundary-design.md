# 曲線の地面境界（第1段階のみ）

最新ユーザーの「リリース品質改善・第1段階」を実施する。今回の根因は矩形地面の下端／北の側端が素地の芝へ切れ、既存外周の植栽だけでは線が残ること。PDF9+14ページを確認。実機文脈の原本だがインストールSHA／連続10分の記録は未受領。合格を推定しない。

維持：5地区のMasterLayout.Dressing／地面原画／中心構成、既存200外周Sprite、全歩行／衝突／保存／報酬／キャラ／図鑑／BGM／Merge。今回は地面境界の描画だけ。噴水→代表1名2.5D→Mergeは第1段階の実機合格後。main禁止。ユーザーの包括承認とファイル単位停止不要を適用し、新たな確認質問を作らない。

候補は(1)原画全体の再制作（凍結品質への影響が大きい）、(2)植栽だけ増量（前回の残線を解決しない）、(3)既存の原画端を曲線メッシュへ連続させる。今回は著者判断で(3)を採用する。新しい原画／テクスチャ／SDKなし。

TownBoundaryGardenLayout.cs内に純粋なTownBoundaryCurveLayoutを追加。西／東の下端はSouth原画の外（x絶対値>=.92）だけ、北の左右は上端接続以北（y>=1.23）だけ。4本の帯を既存West原画と同じUVで接続し、反射サンプルを外へ延長、0.06〜0.16worldの緩い曲線と短いアルファ羽根で植栽へ移す。内側重なりは最大.006world、同一texelで継ぐ。既存の歩行面・中心地表は切り取らない。

TownBoundaryGardenGraphic.cs内に専用UGUI Graphicを追加（既存West Textureを共有、1バッチ、272頂点、raycast false）。SouthGroundの最後の共有レイヤーに設置し、現行の入口帯／外周植栽より下、住人や既存小物より下。ライブと成長プレビューに同じ投影を使う。

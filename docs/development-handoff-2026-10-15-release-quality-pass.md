## 1. キャラと歩く地域移動

- お気に入りキャラをタップすると、行き先カードを表示します。西のカフェ、中央の噴水、東の花の小道、近くのベンチ、依頼部屋、ショップを選択できます。
- 西のカフェ前は既存のLv.2条件に従い、それまではカフェのお庭へ案内します。成長後の花の小道／散歩道／お祝いの道も一覧の下へ追加します。
- 既存B案の経路を再利用し、出口へ歩く→約0.30秒の軽いフェード→隣地域の入口→目的地へ歩きます。西↔東は中央経由です。
- 依頼部屋／ショップは入口まで歩き、到着後の「入る」で画面を開きます。入る前に施設が分かる既存の安全な導線を維持します。
- 上部3ボタンは1タップの歩行ショートカットです。押下時は文字を縮め、48単位の操作領域は縮めません。移動先と移動中表示を出します。同じ行き先の連打は歩行を最初からやり直しません。
- 別の行き先への変更、中断、設定、pauseはB案のキャンセル処理へ接続しています。フェード中の追加入力は受け付けません。
- 「景色だけ見る」はキャラカード内に分離しました。別地域を眺めているときは、主人公のいる地域のボタンを明示的な「主人公へ戻る」にします。
- 地域位置は従来どおり一時状態です。アプリ再起動時は中央へ戻り、既存の進行・お気に入りは保存から復帰します。地域位置を保存v3に追加していません。

## 7. Windowsで次に行う操作

1. Unityを閉じます。GitHub Desktopで `mofumachi-merge` を開き、**Fetch origin** を押します。
2. **Current branch** から **`feat/release-quality-pass-20261015`** を選択します。旧B案やmainと取り違えないでください。必要なら **Pull origin** を押します。
3. Unity Hubから同じプロジェクトを **6000.6.4f1** で開き、インポート／コンパイルが終わるまで待ちます。
4. **ウィンドウ（Window）→ 一般（General）→ Test Runner** を開きます。
5. **EditMode → Run All**。完了後 **Export Results** で、デスクトップに作った `Mofumachi-QA-20261015` フォルダーへ `QualityPass-EditMode.xml` として保存します。
6. **PlayMode → Run All**。同じフォルダーへ `QualityPass-PlayMode.xml` として保存します。
7. 両XMLで全件Passed、failed 0、skip 0を確認します。目安139／135ですが、実発見・XMLを優先します。旧138／124だけで今回版合格とはしません。上記地域suiteと新規QualityPass suiteが必要です。
8. 両XMLを共有してください。失敗があればこの候補上で修正し、APKへ進みません。
9. 全件合格確認後、**Mofumachi → Android → Build Town QA APK (separate save)** を実行します。成果物は通常 `Builds\Android\town-life-qa.apk`。commit、更新日時、サイズ、SHA256を記録します。以前のB案APKを今回版の成果物として流用しません。
10. 同じ `com.mofumachi.merge.qa.townlife` に更新インストールします。アンインストール／アプリデータ削除はしません。

CLIを使う場合は、Unityを閉じてプロジェクトフォルダーのPowerShellから `scripts/build-android.ps1 -TownQa`。新しい実行用フォルダーに両XML・ログ・APK・`build-info.json` を作ります。今回の地域／QualityPass suite不足、失敗、skipは生成前に拒否します。

# 後退を止めるベース版 Quality Pass

2026-10-21ユーザー指示を仕様とする。既存の5エリア／平面5×6内の品質調整。今回の包括承認により内部実装を継続し、追加の計画承認待ちは設けない。

## 体験と範囲

中央の噴水を基準に、花の縁・木陰・座席・灯りが散歩道の先に見える街にする。中央から4方向への既存の道・カメラ・入口・IDを保つ。同じ植物・舗装・街灯を接続にも使う。5つの不連続な背景には戻さない。画面端へ植栽を足すだけでなく、噴水脇と道沿いの滞在場所を構成する。大きな空白と石の過大な反復を抑える。

Mergeは平面の30個の48単位以上の入力矩形を維持。既存原画を最大限に表示し、強い文字のLv帯に絵が隠れないようにする。ミント／ピーチの浅い陶器色、ローズと金の盤面枠、明確なピンクの選択と緑の候補。既存の持ち上げ・キラキラ・着地・Lv.UPを維持する。保存盤面を埋めて見栄えを偽らない。

## 凍結

TOP本文、ロゴ、6名の絵、全既存画像・音源、図鑑・日次・音設定、Coreのセーブ／納品／報酬／依頼／5×6を基準SHAで固定。セーブ初期化なし、課金／ガチャ／SDKなし、main統合なし。キャラは現行の軽量モーションの範囲に留める。

## 実装

既存アトラスを共有し、TownVillageDressingの配置と床の物理境界を一致させる。ベンチ・街灯を追加のTextureなしで描く。中央の構成を同じ部材で西カフェ・東花屋・北小屋・南庭に展開する。新しい植栽はLv0から見える基礎を持ち、未来の装飾のための見えない障害物を作らない。成長の花／席／アーチはLvによる差を残す。歩行量を消費する一律の柵囲みはしない。

近いNPCは身体の足元距離だけでなく見た目の横幅にも配慮して回避する。停止先の予約／入口直前の退避／到達時間が悪化しないか全移動テストで検査する。名札が近い人の顔を隠す場合は優先度を付けて控える。

## 後退防止と合格

凍結ファイルSHA、連続路・噴水両側・施設までの経路、30入力とドラッグ、図鑑／日次／保存回帰を自動検査。画像やテスト数を改善の証明にはしない。旧bd3f357の102枚と同名の撮影工程・Lv・720×1280、新版のUnity描画を比較する。9月22日基準との比較は中央とMergeを必須とする。

PNGとソースが一致しても採用は自動化しない。見た目・操作・情報・世界観・FPS・Pixel負荷を別々に判定し、未確認なら保留。PixelのBeforeとAfterを同じ保存／開始地点／操作時間で撮り、描画時間とPSSを記録する。FPS・負荷に後退があれば採用を保留する。静止画からFPSを推測しない。

このクラウドではUnityライセンス・Android Build Support・Pixel USB経路がないことが既に確認されている。C#の実DLL参照コンパイルをUnity実描画と呼ばない。今回ソースのUnity／APK／Pixelが揃うまで完成も採用も保留する。

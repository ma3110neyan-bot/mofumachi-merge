## 1. 推奨ゲームループ・採用推奨

街で会話・散策 → もふポイント獲得 → Lv1のお茶・パン・花を生成 → 無料で合成 → 依頼へ納品 → 依頼達成数と街行動の累計ポイントに応じて街成長。

生成だけにポイントを使い、合成・移動・納品は無料とする案を推奨する。Lv上限は増やさず、Lv1〜6内の依頼を計12件にする。標準プレイでLv3は2日目、Lv6は7〜9日を目標とする。採用済みではない。

既存6依頼だけを待ち時間で引き延ばすことを避け、既存3系統・Lv1〜3の組み合わせで内容を増やす。キャラ・アイテム・街のグラフィック、盤面、UI配置、フォント、Visual Lock、BGMは変更しない。

## 2. ポイント獲得案

仮称は「もふポイント」。既存Coinsとは別に扱う提案。

| 獲得元 | 提案値 | 通常の日次獲得 |
| --- | --- | ---: |
| 会話 | 異なる相手の当日初回に4P、最大3名 | 12P |
| 街の散策 | 散策完了で6P、当日2回まで | 12P |
| 今日のお花 | 既存条件で受領時に8P、当日1回 | 8P |
| 日次回復 | 当日の初回起動時に16P加算 | 16P |
| 通常分終了後の散策 | 約2分の実操作を伴う散策で2P、繰り返し可能 | 追加プレイ分 |
| 時間による自動回復 | 採用しない | 0P |

- 初期所持24P、所持上限96P、通常の日次供給48P。
- 日次回復は残高初期化ではなく加算。残高は持ち越すが、休んだ日の日次回復をまとめて付与しない。
- 会話・散策・図鑑閲覧はポイント不要。報酬上限後も交流と既存の図鑑進行は続けられる。
- 依頼納品のポイント還元は0P。既存Coinsをポイント収支へ算入しない。
- 街成長用の累計は会話・散策・お花による「街行動の累計獲得P」。初期配布・日次回復を除き、通常32P／日。所持上限で使える残高が増えない場合も、行動した分の累計は記録する案。
- 0Pでも無料の散策で2Pを得て生成へ戻れる。翌日待ちを必須にしない。散策の具体的な完了・実操作判定は実装時確認事項。
- 日次回復16PでLv1を8個生成できるため、日課の3合成を始められる。お花受領を唯一の補給源にして循環停止させない。

## 3. Merge消費案・依頼の難度

生成と合成を分け、二重に消費させない。

| 系統 | Lv1を1個生成 | Lv2を1個作る実効コスト | Lv3を1個作る実効コスト |
| --- | ---: | ---: | ---: |
| お茶 | 2P | 4P | 8P |
| パン | 2P | 4P | 8P |
| 花 | 2P | 4P | 8P |

Lv2にLv1が2個、Lv3に4個必要なので、実効コストは段階に応じて増える。ドラッグ合成・移動・納品の追加消費は0P。生成失敗、盤面満杯、保存失敗では消費しないことを実装時の必須条件とする。

| 到達段階 | この段階の依頼数 | 要求例 | 1件のLv1換算量 |
| --- | ---: | --- | ---: |
| Lv1 | 1件 | お茶Lv2×1 | 2個 |
| Lv2 | 1件 | パンLv2×1＋花Lv1×2 | 4個 |
| Lv3 | 2件 | 花Lv2×1＋パンLv2×1＋お茶Lv1×2 | 各6個 |
| Lv4 | 2件 | お茶Lv3×1＋花Lv2×2＋パンLv2×1 | 各10個 |
| Lv5 | 3件 | お茶Lv3×2＋花Lv2×2＋パンLv3×1 | 各16個 |
| Lv6 | 3件 | お茶Lv3×2＋花Lv3×2＋パンLv2×2 | 各20個 |

同段階でも種類・Lv・数量の組み合わせを変える。表は難度配分と要求例であり、12件すべての正式レシピ・IDを確定したものではない。

この配分の合計は146個のLv1相当。初期のお茶2個を使う場合、追加生成144回・必要288P。寄り道、試作、廃棄による消費を含まない。既存6依頼とのID・物語上の対応は未確定。

## 4. Lv1〜Lv6進行案

依頼数と街行動の累計Pの両方を満たす条件。累計Pは消費しない。表のプレイ時間は累計目標であり未実測。

| 到達Lv | 必要依頼数・累計 | 必要な街行動P・累計 | 累計プレイ時間の目標 | 到達日目安 | 既存の街変化 |
| --- | ---: | ---: | --- | --- | --- |
| Lv1 | 1件 | 4P | 3〜5分 | 1日目 | お茶会のお花 |
| Lv2 | 2件 | 8P | 10〜15分 | 1日目 | カフェの席・花の小道 |
| Lv3 | 4件 | 40P | 25〜40分 | 2日目 | 街灯・ベンチなど |
| Lv4 | 6件 | 96P | 40〜60分 | 3〜4日目 | 工房・花屋周辺の飾り |
| Lv5 | 9件 | 160P | 65〜100分 | 5〜6日目 | お祝いのアーチ |

街変化は既存のものを利用し、新しい建物・エリア・グラフィックは追加しない。会話・図鑑・3系統の生成を後半Lvまで新たにロックしない。

通常の街行動32P／日では、40Pに2日目、224Pに7日目が目安。追加散策で早める余地を残し、日付による強制停止は設けない。最速到達時間・日数は未確認。「約10分でLv3にならない」という実測保証ではない。

## 5. 1日プレイ想定

| 項目 | 標準案 |
| --- | --- |
| プレイ時間 | 10〜20分 |
| 獲得ポイント | 通常48P |
| うち街成長用の累計 | 32P |

将来の課金は追加生成・追加プレイの余地として検討できるが、無料の回復・散策を維持する。購入分を街行動の累計へ直接加える設計は推奨しない。今回、課金仕様・価格・広告・実装は確定しない。

## 6. 離脱リスク

| リスク | 対応案 |
| --- | --- |
| 0Pで遊びが止まる | 会話・散策・既存アイテム合成は無料。散策で再生成できる |
| 会話が報酬回収作業になる | 報酬対象は3名まで。以後も交流・図鑑進行を維持 |
| 納品したのに街が変わらない | 足りない依頼数・街行動Pを明示。「あと1お届け」固定表示は要調整 |
| 後半が数量作業になる | 3系統・Lv1〜3を組み合わせ、単一素材の大量要求を避ける |
| 同じ散策の反復になる | 追加散策を標準進行の必須条件にしない |
| 既存プレイヤーに不利益が出る | 所持品・完了依頼・街Lvを下げない移行方針を別途確認 |

## 7. 調整案

調整は依頼内容と日次供給から行い、合成への追加課金は避ける。以下は今後の評価時の候補であり、今回適用しない。

- 序盤が重い：Lv2までの要求量を先に減らす。初期配布増量は次候補。
- 後半が重い：Lv5〜6のLv1換算量を約20%減らす。
- 進行が速い：種類・Lvの組み合わせを増やす。待ち時間・生成コストの一律引き上げは後順位。
- 0Pからの復帰が苦痛：追加散策を2Pから4Pへ調整する候補。ただし到達日数を再計算する。

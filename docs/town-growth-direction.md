# 街づくりと見た目の成長案

2026-10-11。**仲間の依頼を受け、マージで品物を作って届け、その成果で街を育てる**コンセプトです。以下の外観は提案であり、実装済みの機能ではありません。

## 現在できること

最初のお茶Lv.2を1個納品すると、30 Coinsと街Lv.0→1を保存し、星・拡縮・ファンファーレで成長を表示します。街の背景は全レベルで共通で、建物や花壇の外観切り替えは未実装です。

標準の依頼カタログは1件です。Lv.2以上まで遊ぶには依頼と成長条件の追加設計が必要です。完了済みの同じ依頼を繰り返して報酬や街レベルを増やす処理はありません。

## 外観の段階案

街の道・建物の位置と現在の美しい雰囲気を保ち、花・照明・装飾を積み重ねます。

| 段階案 | 景色に残る変化 |
| --- | --- |
| Lv.0：はじまりの街 | 現在の街並みを基準にした、落ち着いた広場 |
| Lv.1：お茶会の街 | 依頼部屋の前に花鉢と小さな歓迎リボン |
| Lv.2：花いっぱいの広場 | 花壇の色と量が増え、ベンチ周りに彩り |
| Lv.3：きらめく噴水 | 噴水の装飾、水の輝き、広場のタイルを充実 |
| Lv.4：にぎわう街角 | 店先の看板・日よけ・街灯を華やかに |
| Lv.5：祝祭のもふまち | 花のアーチ、ガーランド、街全体の装飾を統一 |

成長時は変更場所を短く強調し、少量の花びらや仲間の反応を添える案です。レベル番号・成長条件・追加依頼は未承認で、今回のゲームルールには入れていません。Lv.4の店先は外観の案で、ショップの購入機能や課金も未実装です。

## 最初に作る範囲の提案

既存の一周と保存復帰のPixel確認後、**初回のLv.0→1で一か所が変わり、その景色が再起動後も残る**ところから始めるのが適切です。多段階の街・建築・ショップを同時に広げず、まず「成果が景色に残る」ことを完成させます。

外観は保存済みの街レベルから決め、演出の途中で終了しても報酬や成長条件を二重に処理しない設計を維持します。共有する背景へ小さな装飾レイヤーを足す方式を第一候補とし、Pixel 3aのメモリとフレームレートを測定します。

# ノア1名：原画を維持する2.5D再試作

ユーザーは現試作を不合格とし、陰影・奥行き・接地・一連動作を明確に改善するよう指示した。原画・顔・配色・服・体型・キャラクター性は維持。他5名、街、承認済み北境界、噴水、図鑑、BGM、Save／依頼／納品／報酬、Mergeは変更しない。採用と5名展開には後のユーザー承認が必要。

前回の実画像では白一色の頂点色、全頂点Z=0、弱い傾きと局所手振りが主因で、既存2Dとの差が読み取れなかった。今回は同じatlas／UGUIメッシュを使う軽いレリーフ表現を選ぶ（実装判断）。フル3D、原画描き直し、新しい重い照明／Particleは使わない。

- 元UVを保った薄い凸面と小さな左右yawで、原画に厚みを感じさせる。顔の描き足し・ミラーはしない。変形の折れ・目／尾の伸びを防ぐ。
- ニュートラルな頂点明暗で顔と身体の丸み／顎下を表す。RGB同率の軽い陰影で色相とalphaを保持、黒つぶれや点滅を作らない。
- ノアだけ、足元固定の柔らかな楕円影へ切り替える。既存2影を残して比較OFFでは元どおり。追加影は1Graphic・白UIテクスチャ・低頂点数、非raycast。影は跳ねない。
- 元の手足の範囲で歩行と挨拶を読み取れる振幅にし、顔・帽子・尾を局所的に引き裂かない。歩行開始／停止・方向転換は既存の補間を使う。目は既存正式目のみ。
- 描画順の基準は世界の足Y、厚み・呼吸・上下動でSortingを変えない。
- 実Unityの静止→歩行→停止→方向転換→会話を、同一エピソードの連続標本で提出する。ノアが発話者であることを確認し、補助的なSorting表示例も分けて示す。固定刻みを実時間FPSと呼ばない。

撮影は比較用の旧不合格版／新版PNG対と、1/30刻みを2stepごとにJPEG化する144コマ／9.6秒の連続標本を使う。歩行の足運びや往復手振りを粗い標本で見誤らないため、当初5標本/秒案から15標本/秒へ上げる。コマはJPEGにして転送量を抑え、因果ピクセル比較はPNGのまま保持する。これはゲームの実測FPSではない。

内部仕様選択の再承認で止めず、ユーザーの詳細指示／AGENTS13に沿って実装する。途中は関連する最小検査だけ。見た目の承認候補へ達する前に全件QA／新APK／Pixel負荷成功を主張しない。旧1/1成功とPixel未確認の記録は履歴として保持する。
